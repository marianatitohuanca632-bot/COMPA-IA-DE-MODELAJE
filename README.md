## Cómo está construido
- **Semántica:** [Utilicé etiquetas HTML5 como header, nav, main, section, article, table, form, aside y footer para organizar el contenido de la página.]
- **Layout:** [Utilicé Flexbox en la cabecera y el menú para distribuir los elementos, y Grid para organizar el contenido en columnas. También usé media queries para adaptar el diseño a pantallas grandes.]
- **Diseño:** [Elegí colores morado, azul, rosa y marrón para darle un estilo llamativo y elegante. Utilicé las tipografías Didot, Bodoni MT y Times New Roman, además de bordes y espacios para mantener el contenido ordenado.]

## Lo más difícil
[Una de las dificultades que tuve fue organizar los elementos de la página para que se vieran ordenados tanto en computadoras como en dispositivos móviles. Para solucionarlo, utilicé Flexbox en la cabecera y en el menú de navegación, junto con la propiedad flex-wrap, que permite que los elementos pasen a otra línea cuando no hay suficiente espacio. También utilicé una media query para cambiar la distribución de la página en pantallas más grandes. Otro aspecto que tuve que revisar fue la organización de las etiquetas HTML para que cada sección tuviera una estructura adecuada.]
